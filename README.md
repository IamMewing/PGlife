# PG Life

A responsive PG booking website designed for students and working professionals to search for paying guest accommodations across major Indian cities.

## Features

- Responsive UI
- Login & Signup Modals
- Search Bar
- Major Cities Section
- Bootstrap Components
- Responsive Navigation
- Mobile Friendly Layout
- Hero Banner
- Property Navigation

## Tech Stack

- HTML5
- CSS3
- Bootstrap 4
- JavaScript
- Font Awesome

## Future Improvements

- Backend Integration
- User Authentication
- Database
- Property Filtering
- Payment Gateway
